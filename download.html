安装与第一次打开

  1. 第 1 步

    双击下载的 .dmg，把 RelayForge 拖到「应用程序」。

  2. 第 2 步

    第一次打开会提示“无法验证开发者”，点「完成」。然后打开「系统设置 → 隐私与安全性」，拉到底部点「仍要打开」，输入开机密码。只需做一次。

  3. 第 3 步

    点左下角「设置」，选择 Claude Code 或 Codex。

  4. 第 4 步

    逛完演示项目后，点左上角「项目 ▾ → 打开其他目录…」接入你正在做的仓库。AI 会先读一遍代码，生成产品大图的第一版草稿。

为什么会有这个提示？

RelayForge 还没有做 Apple 公证（需要付费的开发者账号），macOS 会对所有未公证的应用这样提示，并不代表文件有问题。可以用上面的 SHA-256 核对文件。

如果提示「已损坏，无法打开」，在终端运行下面这行，再重新打开：

xattr -dr com.apple.quarantine /Applications/RelayForge.app

从源码构建

不想装未公证的安装包，也可以直接从源码运行。需要 Node.js 20+ 和 Python 3.10+。

GitHub 上的完整说明 ↗
git clone https://github.com/tcjacker/relayforge.git cd relayforge/app npm install npm start

RelayForge 0.1.0 2026-11-23 · 最新 
RelayForge 0.1.0 是首个源码公开版本。

RelayForge 是一个 macOS 本地桌面开发工作台：在应用里管理需求、问题和日常聊天，把 Claude Code 或 Codex 会话嵌在窗口里，围绕每个需求自己的 Git 分支和工作目录完成立项、开发、测试、验收和合并。

## 下载

| 你的 Mac | 下载 |
|---|---|
| Apple Silicon（M 系列） | `RelayForge-0.1.0-arm64.dmg` |
| Intel | `RelayForge-0.1.0.dmg` |

也提供同架构的 ZIP。文件校验值见 `SHA256SUMS.txt`。

## 运行需要

- macOS
- Python 3.10+ 和 Git
- 使用 AI 会话时，需要已安装并登录的 Claude Code 或 Codex CLI

打开后会先看到虚构的演示项目，浏览它不会调用模型。

## 首次打开

这个版本使用临时签名，**没有 Apple Developer ID 签名，也没有经过 Apple 公证**，macOS 可能会拦下它。把应用拖进「应用程序」后，如果打不开，到「系统设置 → 隐私与安全性」点「仍要打开」。
