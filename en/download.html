Install and first launch

  1. Step 1

    Open the downloaded .dmg and drag RelayForge into Applications.

  2. Step 2

    The first launch says the developer can't be verified — click Done. Then open System Settings → Privacy & Security, scroll down, click Open Anyway and enter your password. You only do this once.

  3. Step 3

    Click Settings in the lower-left corner and pick Claude Code or Codex.

  4. Step 4

    When you're done with the demo, use Project ▾ → Open another folder… to connect the repository you're working on. AI reads the code first and drafts the first version of your product map.

Why the warning?

RelayForge isn't notarized by Apple yet (that needs a paid developer account). macOS shows this for every un-notarized app; it doesn't mean the file is unsafe. You can verify it with the SHA-256 above.

If macOS says the app “is damaged and can't be opened”, run this in Terminal and open it again:

xattr -dr com.apple.quarantine /Applications/RelayForge.app

Build from source

Prefer not to install an un-notarized app? Run it from source. Needs Node.js 20+ and Python 3.10+.

Full instructions on GitHub ↗
git clone https://github.com/tcjacker/relayforge.git cd relayforge/app npm install npm start

RelayForge 0.1.0 2026-11-23 · Latest 
RelayForge 0.1.0 是首个源码公开版本。

RelayForge 是一个 macOS 本地桌面开发工作台：在应用里管理需求、问题和日常聊天，把 Claude Code 或 Codex 会话嵌在窗口里，围绕每个需求自己的 Git 分支和工作目录完成立项、开发、测试、验收和合并。

## 下载

| 你的 Mac | 下载 |
|---|---|
| Apple Silicon（M 系列） | `RelayForge-0.1.0-arm64.dmg` |
| Intel | `RelayForge-0.1.0.dmg` |

也提供同架构的 ZIP。文件校验值见 `SHA256SUMS.txt`。

## 运行需要

- macOS
- Python 3.10+ 和 Git
- 使用 AI 会话时，需要已安装并登录的 Claude Code 或 Codex CLI

打开后会先看到虚构的演示项目，浏览它不会调用模型。

## 首次打开

这个版本使用临时签名，**没有 Apple Developer ID 签名，也没有经过 Apple 公证**，macOS 可能会拦下它。把应用拖进「应用程序」后，如果打不开，到「系统设置 → 隐私与安全性」点「仍要打开」。
